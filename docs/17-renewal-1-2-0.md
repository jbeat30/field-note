# 1.2.0 디자인 리뉴얼

크림 바탕에 주황 평면과 잉크 면을 겹치는 새 시각 방향을 모든 화면에 적용한다. 기능, 데이터, 문구는 그대로 두고 모양만 바꾼다. 기준 시안은 디자인 핸드오프 폴더(`design_handoff_field_note_redesign`)에 있다.

## 진행 방식

- `feature/1.2.0`에서 화면 단위로 기능 브랜치를 만들고 브랜치마다 커밋 3~15개로 작업한다
- 브랜치마다 타입·린트·서식·주석·빌드·스토리 테스트를 통과시키고, 실제 화면을 띄워 동작과 모양을 확인한다
- 기능 브랜치는 `feature/1.2.0`까지 CI 통과 후 머지한다. 릴리즈 브랜치로 가는 PR은 만들기만 하고 머지는 사용자가 한다

## 로그인 전 화면

- 공통 틀(`AuthLayout`): 주황 평면 위에 큰 제목, 아래 잉크 띠에 걸친 인력 배치 소개 패널, 오른쪽 크림 폼 카드. 좁은 화면은 로고와 폼 카드만 보인다
- 로고는 `BrandLogo`(세 줄 막대, 이름, 베타 표시)로 분리해 사이드바에서도 쓴다
- 약관과 개인정보 처리방침 링크는 카드 안 아래쪽에 둬서 잉크 띠 위에서도 읽힌다
- 테스트 계정 안내는 잉크 면에 라임 버튼, 소셜 로그인 버튼은 브랜드 색을 유지하고 모서리만 맞춘다

## 앱 틀

- 사이드바(`AppSidebar`): lg 이상은 잉크 면 264px, 접으면 96px 아이콘만(이름은 마우스를 올리면 툴팁), md는 아이콘과 글자가 세로로 놓인 92px 레일. 접힘은 저장하지 않고 화면을 새로 열면 펼친 상태
- 머리 구조(시안 기준): 전역 상단 줄은 없고, 각 화면의 주황 평면에 제목과 화면별 버튼만 놓인다. 찾기 알약, 알림 원, 프로젝트 등록 알약은 홈 머리에만 있고 프로젝트 목록 머리에는 등록 알약만 있다
- 모바일 상단 줄: 로고, 찾기 원 버튼, 알림 원 버튼. 화면 밝기 전환은 더보기 시트로 옮겼다
- 주황 평면: `.plane` 클래스(면을 좌우 끝까지 펼치고 안쪽 색을 밝은 모드 값으로 고정), 1단계 `PageHeader`가 스스로 깔고 바깥 틀이 가로 넘침을 잘라냄
- 모바일: 주황 상단 줄(로고, 알림, 테마)과 잉크 알약 하단 메뉴 5칸, 빠른 추가는 주황 원 버튼
- 메뉴 목록은 `navItems.ts`에서 사이드바와 하단 메뉴가 함께 씀

## 홈

- 제목은 `PageHeader`의 `overlap` 옵션으로 평면을 길게 깔고, 지표 타일(라임·크림·크림·잉크)이 평면 경계에 걸쳐 놓인다. 불러오는 중과 오류 안내는 겹치지 않고 평면 아래에 둔다
- 머리는 시안(04)대로 `회사명 · 날짜` 한 줄, 큰 제목 `안녕하세요, 이름님`, 오른쪽에 검색 알약(돋보기·입력·잉크 찾기 버튼), 알림 원, 폴더 더하기 아이콘의 등록 알약이다. 좁은 화면은 등록 알약이 전체 폭으로 제목 아래에 놓이고 찾기와 알림은 상단 줄에 있다
- 확인할 일은 카드 안의 둥근 행으로, `이동`은 잉크 알약 버튼이다
- 이번 달 인력 달력은 둥근 칸과 프로젝트 칩으로 바꿨고 칩 색은 `lib/projectTone.ts`의 `projectChipClass`로 인력 배치 화면도 함께 쓴다
- 제안 상태인 "오늘 기록이 필요해요" 카드와 "표에서 보기"는 승인 전이라 만들지 않았다

## 프로젝트 목록과 등록

- 목록은 공통 컴포넌트 변경(칩, 표 머리선, 배지)으로 새 모양이 적용되고 별도 구조 변경은 없다
- 돌아가기 링크는 `PageHeader`의 `back` 옵션으로 주황 평면 안에 놓는다. 직원·명부·설정 화면에서도 같은 옵션을 쓴다
- 포커스는 잉크 테두리만 쓰고 바깥 주황 링은 쓰지 않는다
- 입력 칸은 모래색 채움이라 바탕(모래색) 위에 바로 놓으면 보이지 않는다. 입력 칸은 항상 크림 카드 안에 둔다 (등록 폼을 카드로 감쌌다)
- 묶음 제목(`legend`)은 전역 CSS로 묶음 안쪽 맨 위에 놓는다

## 프로젝트 작업 공간

- 머리: 주황 평면에 돌아가기·번호·상태·이름·주 버튼을 놓고, 현장·고객·담당자·기간은 평면 경계에 걸친 잉크 면에 둔다
- 10개 탭은 코드 동작 그대로 가로 스크롤하며 트랙(`--track`) 안의 알약으로 바꿨다. 마감·보증 하위 탭도 같은 모양
- 작업 달력은 둥근 칸으로, 기록 있는 날은 옅은 주황 면, 오늘은 주황 원
- 나머지 탭 화면(현황·인원·비용·사진·메모·문서·공수·추가 공사·마감·보수·보증·일보)은 공통 컴포넌트 변경으로 새 모양이 적용된다
- 입력 칸과 보조 버튼은 모래색 면이라 같은 색 바탕 위에서 사라지지 않도록 옅은 윤곽선(`--control-border`)을 둔다
- 로고는 크기 단계가 둘이다: 로그인 전 화면(막대 7px, 폭 30·20·26px)과 사이드바·모바일 상단(막대 5px, 폭 20·14·17px)

## 직원과 명부

- 직원 목록 머리: 크림 알약 이동 버튼(인력 배치 보기, 월 공수표)과 잉크 알약 등록 버튼(사용자 더하기 아이콘), 제목 아래 평면 안에 탭(직원 목록, 단가표)
- `PageHeader`의 `tabs` 슬롯이 평면 안 탭을 담고, 평면 바로 아래 카드는 `.plane-page` 규칙으로 평면 경계에 걸친다 (글자 줄에는 적용하지 않음)
- 필터는 라벨이 위에 붙은 크림 카드에 두고 입력 칸은 윤곽선 없는 모래색 채움이다. 모래색 바탕에 바로 놓이던 컨트롤(사진 구역 찾기, 문서 검색, 추가 공사·보수 상태 필터, 일보 날짜)은 크림 카드로 감쌌다
- 표 요약줄은 굵은 `N명`과 밑줄 있는 `쪽당 10개`로 바꿨다
- 직원 카드와 명부 카드는 돌아가기 링크, 이름 제목, 평면 안 탭 순서이고 지표 타일이 평면 경계에 걸친다. 글자 값이 긴 지표는 한 단계 작은 크기로 한 줄에 맞춘다

## 월 공수표와 인력 배치

- 월 공수표: 돌아가기 링크, 확정 배지, 제목, 크림 알약 `엑셀로 내보내기`와 잉크 알약 `공수 확정`이 평면 안에 놓이고 달 이동은 크림 카드, 지표 타일은 카드 밖에 그대로 둔다
- 인력 배치: 달 이동과 보기 기간(1주·2주·월) 전환을 한 카드에, 요약 줄과 표를 다른 카드에 묶었고 오늘 열 머리는 주황으로 채운다
- 지표 타일 면 규칙: 첫 칸 라임, 가운데 크림, 칸이 정확히 네 개일 때만 마지막 칸이 잉크(주황 숫자)

## 설정

- 설정 머리: 제목, 설명, 크림 알약 `로그아웃`, 평면 안 탭(내 계정·회사 관리·기타)과 탭마다 바뀌는 한 줄 안내
- 알림 설정, 활동 기록, 목록 관리는 `PageHeader`의 `back`으로 돌아가기 링크를 평면 안에 둔다

## 시안 값 보완

- 시안 HTML의 인라인 값을 그대로 옮긴다: 카드 모서리 34, 안쪽 여백 26과 30, 제목 21px 굵게, 보조 링크는 밑줄만(주황 밑줄 아님)
- 홈 진행 중 프로젝트와 확인할 일 카드는 420px 같은 높이이고 목록만 안에서 스크롤한다. 표 머리는 고정, 확인할 일 제목 옆에 주황 개수 표시, 알림 행은 점·글·잉크 `이동` 알약·`숨기기` 글자가 한 줄
- 이번 달 인력 달력: 칸 `#f3ecdb` 둥근 16, 선택 칸 `#ffe4d3`와 잉크 2px 윤곽, 겹침 칸 위험색 윤곽, 오늘 숫자는 잉크 알약, 토요일 숫자는 파랑, 선택한 날 상세는 잉크 패널
- 지표 타일: 모서리 30, 여백 22와 24, 숫자 54px(모바일 34px), 그림자 `0 8px 12px -7px`
- 보조 글자는 `--sub`(밝음 `#6b6152`, 어두움 `#a89c84`, 주황 평면 안 `#2a2118`) 고정 색으로 통일했다. 투명도로 만든 회색은 카드 색에 따라 달라 보이기 때문이다

## 화면 상태와 작업 공간 보완

- 알림 창: 이동과 숨기기는 굵은 글자 버튼, 하단은 모래 알약 `알림 설정`과 잉크 알약 `모두 숨기기`
- 검색 결과: 그룹별 크림 카드와 안쪽 행의 두 열 구조, 제목 옆 건수
- 빠른 추가 시트: 위 모서리 30, 안쪽 행(이름과 화살표), 오른쪽 위 닫기 아이콘
- 오프라인 안내와 시연 안내는 잉크 띠에 작은 글자(`#d9cfb9`), 이어서 작성은 크림 카드 안 행
- 프로젝트 머리: 번호와 상태가 크림 알약, 현장·고객·담당자·기간은 평면 위 한 줄 글자, `오늘 기록`은 연필 아이콘 잉크 알약, 탭 트랙은 평면 경계에 걸친다
- 작업 달력 위에 지표 타일 3개(이번 달 기록한 날, 일한 시간, 오늘 상태): 지표 타일은 `surface`로 면(라임·크림·잉크·주황)을 정할 수 있다

## 화면 전체 흐름 시험

- 로그인 확인 기준은 홈의 큰 인사 제목(`안녕하세요`)이다. 회사 이름은 제목 위 한 줄로 옮겨졌다
- `desktopShell.spec.ts`가 1440 폭에서 사이드바 접기와 펼치기, 홈 머리 검색, 프로젝트 목록 등록 알약을 확인한다
- 로컬에서 `pnpm infra:up`, `pnpm db:setup`, `pnpm db:seed` 뒤 `E2E_WEB_PORT=4650 pnpm e2e`로 돌린다 (5173은 Windows 예약 포트일 수 있어 다른 포트를 쓴다)

## 전수 대조 보완 (2차)

- 로그인 전 화면: 시안 A1 치수(카드 480, 잉크 띠 아래 3분의 1, 14칸 인력 배치 장식 패널)를 따르고 넓은 화면에서 페이지 스크롤이 없다. 높이가 820px 이하면 장식 패널을 숨기고 카드 안에서만 스크롤한다. 기기가 다크 모드여도 `auth-light` 범위로 밝은 색을 쓴다
- 소셜 로그인은 `VITE_SOCIAL_LOGIN=true`일 때만 로그인, 가입, 설정에 나온다 (기본은 숨김)
- 링크 밑줄은 쓰지 않고 호버 시 `text-sub`로 글자색만 바꾼다
- 명도 대비: 투명도 글자(`text-foreground/40` 등)를 `text-sub`로 바꾸고 입력 안내 글자, 비활성 버튼과 입력 칸을 보조 글자색 위에 놓았다. 모든 화면의 글자색과 배경색을 브라우저에서 계산해 밝은 모드와 어두운 모드 모두 4.5 대 1 미만이 없음을 확인했다
- 주황은 `#ee6f3d`, 라임은 `#d6e382`로 한 단계 차분하게 조정하고 타일 두께 테두리도 같은 계열로 맞췄다
- 배지는 시안 값(안쪽 여백 3·11, 12px 굵게, 상태별 파스텔 면과 진한 글자)으로 맞췄고 칩은 높이 36, 탭은 굵은 14px로 맞췄다
- 회사 기준값: 근무 형태는 선택 칸, 공수 입력 방식은 알약 전환으로 시안과 같게 바꿨다
- 불러오는 중에는 안내 글 대신 막대 자리표시(`LoadingBlock`)를 보이고 안내 글은 스크린 리더에만 전달한다

- 카드 안의 카드(프로젝트 등록의 현장·일정 구역 등)에서는 입력 채움을 카드색으로 바꿔 입력 칸이 배경에 묻히지 않게 했다. 체크·라디오 테두리는 보조 글자색으로 진하게 했다
- 작업일 입력 화면의 머리 제목은 시안처럼 날짜이고 프로젝트 이름은 아래 정보 줄 맨 앞에 둔다

## 전수 대조 보완 (3차)

- 사이드바와 모바일 상단의 베타 배지는 시안처럼 주황 채움에 잉크 글자 알약이다. 로그인 화면의 큰 로고 옆 배지만 테두리형이다
- 모든 입력 칸에 안내 문구(placeholder)를 넣었고 색은 보조 글자색이라 4.5 대 1을 지킨다
- 로그인 인력 배치 패널은 시안처럼 빈 칸은 회색 테두리, 오늘 칸은 주황 테두리, 채운 칸은 같은 색 테두리를 가진다
- 체험해 보기 영역은 서버 `PUBLIC_DEMO_ENABLED=true`일 때 서버가 내려준 공개 시연 계정(tester)으로 로그인한다. 목업에서는 시드 계정으로 켜 둔다
- 안내 상자(Alert)는 시안처럼 테두리와 22px 마크 원을 쓰고 종류별 색을 가진다
- 세로 스크롤바 유무로 화면이 밀리지 않게 `html`에 `overflow-y: scroll`을 두고 로그인 전 화면만 제외한다
- 글꼴이 들어오기 전 글자가 움직이는 현상은 첫 그리기를 글꼴 준비 뒤로 미루고(최대 1.5초) 부드럽게 나타나게 해 줄였다
- 불러오는 중 표시는 글 줄, 목록 줄, 화면 전체 세 모양이고 프로젝트 작업 공간은 머리 평면과 탭 줄 자리를 먼저 깐다
- 프로젝트 목록은 검색 카드, 상태 칩, 필터 카드, 목록 카드 제목(프로젝트 목록 · N건) 구성이고 프로젝트 등록 폼은 기본, 고객·담당자·공종, 기간 세 카드다
- 프로젝트 작업 달력은 월요일 시작이고 토요일은 파랑, 일요일은 빨강이다. 마감 요약 화면은 지표 타일과 카드 안의 요약 시트로 구성했다
- 직원 단가표는 카드 안에 제목과 함께 놓는다

### 공통 컴포넌트 규칙

- 버튼: primary 잉크, secondary 모래, soft 라임. 화면 위쪽 행동 줄은 `pillIconButtonClass`(잉크 알약과 주황 아이콘 원)
- 입력: 모래 채움, 포커스는 잉크 테두리만(바깥 링 없음), 안내 글자는 보조 글자색, 오류는 위험색 테두리와 옅은 면
- 탭·구간 선택: 트랙 안의 알약, 선택은 잉크 채움
- 지표 타일: 라임, 크림, 크림, 잉크(주황 숫자) 순서로 반복
- 제목 평면 안에서는 `--foreground`를 잉크로 고정해 다크 모드에서도 글자가 읽힘
