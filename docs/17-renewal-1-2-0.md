# 1.2.0 디자인 리뉴얼

크림 바탕에 주황 평면과 잉크 면을 겹치는 새 시각 방향을 모든 화면에 적용한다. 기능, 데이터, 문구는 그대로 두고 모양만 바꾼다. 기준 시안은 디자인 핸드오프 폴더(`design_handoff_field_note_redesign`)에 있다.

## 진행 방식

- `feature/1.2.0`에서 화면 단위로 기능 브랜치를 만들고 브랜치마다 커밋 3~15개로 작업한다
- 브랜치마다 타입·린트·서식·주석·빌드·스토리 테스트를 통과시키고, 실제 화면을 띄워 동작과 모양을 확인한다
- 기능 브랜치는 `feature/1.2.0`까지 CI 통과 후 머지한다. 릴리즈 브랜치로 가는 PR은 만들기만 하고 머지는 사용자가 한다

## 로그인 전 화면

- 공통 틀(`AuthLayout`): 주황 평면 위에 큰 제목, 아래 잉크 띠에 걸친 인력 배치 소개 패널, 오른쪽 크림 폼 카드. 좁은 화면은 로고와 폼 카드만 보인다
- 로고는 `BrandLogo`(세 줄 막대, 이름, 베타 표시)로 분리해 사이드바에서도 쓴다
- 약관과 개인정보 처리방침 링크는 카드 안 아래쪽에 둬서 잉크 띠 위에서도 읽힌다
- 테스트 계정 안내는 잉크 면에 라임 버튼, 소셜 로그인 버튼은 브랜드 색을 유지하고 모서리만 맞춘다

## 앱 틀

- 사이드바(`AppSidebar`): lg 이상은 잉크 면 264px, 접으면 96px 아이콘만(이름은 마우스를 올리면 툴팁), md는 아이콘과 글자가 세로로 놓인 92px 레일. 접힘은 저장하지 않고 화면을 새로 열면 펼친 상태
- 한 줄 머리(PC): 찾기, 알림, 프로젝트 등록 순서로 주황 평면 위에 놓임. 페이지 안의 프로젝트 등록 버튼은 좁은 화면에서만 보임
- 주황 평면: `.plane` 클래스(면을 좌우 끝까지 펼치고 안쪽 색을 밝은 모드 값으로 고정), 1단계 `PageHeader`가 스스로 깔고 바깥 틀이 가로 넘침을 잘라냄
- 모바일: 주황 상단 줄(로고, 알림, 테마)과 잉크 알약 하단 메뉴 5칸, 빠른 추가는 주황 원 버튼
- 메뉴 목록은 `navItems.ts`에서 사이드바와 하단 메뉴가 함께 씀

## 홈

- 제목은 `PageHeader`의 `overlap` 옵션으로 평면을 길게 깔고, 지표 타일(라임·크림·크림·잉크)이 평면 경계에 걸쳐 놓인다. 불러오는 중과 오류 안내는 겹치지 않고 평면 아래에 둔다
- 검색 입력은 평면 오른쪽 행동 영역으로 옮겼고(좁은 화면은 전체 폭), 프로젝트 등록은 좁은 화면에서만 보인다
- 확인할 일은 카드 안의 둥근 행으로, `이동`은 잉크 알약 버튼이다
- 이번 달 인력 달력은 둥근 칸과 프로젝트 칩으로 바꿨고 칩 색은 `lib/projectTone.ts`의 `projectChipClass`로 인력 배치 화면도 함께 쓴다
- 제안 상태인 "오늘 기록이 필요해요" 카드와 "표에서 보기"는 승인 전이라 만들지 않았다

## 프로젝트 목록과 등록

- 목록은 공통 컴포넌트 변경(칩, 표 머리선, 배지)으로 새 모양이 적용되고 별도 구조 변경은 없다
- 돌아가기 링크는 `PageHeader`의 `back` 옵션으로 주황 평면 안에 놓는다. 직원·명부·설정 화면에서도 같은 옵션을 쓴다
- 입력 칸은 모래색 채움이라 바탕(모래색) 위에 바로 놓으면 보이지 않는다. 입력 칸은 항상 크림 카드 안에 둔다 (등록 폼을 카드로 감쌌다)
- 묶음 제목(`legend`)은 전역 CSS로 묶음 안쪽 맨 위에 놓는다

## 프로젝트 작업 공간

- 머리: 주황 평면에 돌아가기·번호·상태·이름·주 버튼을 놓고, 현장·고객·담당자·기간은 평면 경계에 걸친 잉크 면에 둔다
- 10개 탭은 코드 동작 그대로 가로 스크롤하며 트랙(`--track`) 안의 알약으로 바꿨다. 마감·보증 하위 탭도 같은 모양
- 작업 달력은 둥근 칸으로, 기록 있는 날은 옅은 주황 면, 오늘은 주황 원
- 나머지 탭 화면(현황·인원·비용·사진·메모·문서·공수·추가 공사·마감·보수·보증·일보)은 공통 컴포넌트 변경으로 새 모양이 적용된다
- 입력 칸과 보조 버튼은 모래색 면이라 같은 색 바탕 위에서 사라지지 않도록 옅은 윤곽선(`--control-border`)을 둔다
- 로고는 크기 단계가 둘이다: 로그인 전 화면(막대 7px, 폭 30·20·26px)과 사이드바·모바일 상단(막대 5px, 폭 20·14·17px)

### 공통 컴포넌트 규칙

- 버튼: primary 잉크, secondary 모래, soft 라임. 화면 위쪽 행동 줄은 `pillIconButtonClass`(잉크 알약과 주황 아이콘 원)
- 입력: 모래 채움, 포커스는 잉크 테두리와 주황 링, 오류는 위험색 테두리와 옅은 면
- 탭·구간 선택: 트랙 안의 알약, 선택은 잉크 채움
- 지표 타일: 라임, 크림, 크림, 잉크(주황 숫자) 순서로 반복
- 제목 평면 안에서는 `--foreground`를 잉크로 고정해 다크 모드에서도 글자가 읽힘
