# 1.2.0 디자인 리뉴얼

크림 바탕에 주황 평면과 잉크 면을 겹치는 새 시각 방향을 모든 화면에 적용한다. 기능, 데이터, 문구는 그대로 두고 모양만 바꾼다. 기준 시안은 디자인 핸드오프 폴더(`design_handoff_field_note_redesign`)에 있다.

## 진행 방식

- `feature/1.2.0`에서 화면 단위로 기능 브랜치를 만들고 브랜치마다 커밋 3~15개로 작업한다
- 브랜치마다 타입·린트·서식·주석·빌드·스토리 테스트를 통과시키고, 실제 화면을 띄워 동작과 모양을 확인한다
- 기능 브랜치는 `feature/1.2.0`까지 CI 통과 후 머지한다. 릴리즈 브랜치로 가는 PR은 만들기만 하고 머지는 사용자가 한다

## 디자인 토큰 (`apps/web/src/index.css`)

| 구분      | 값                                                                                                         |
| --------- | ---------------------------------------------------------------------------------------------------------- |
| 바탕      | 밝음 `#efe8d8`, 어두움 `#0c0b09`                                                                           |
| 카드      | 밝음 `#fbf7ee`, 어두움 `#1a1713`, 카드 안 행 `#f3ecdb` / `#241f18`                                         |
| 입력 채움 | `--field` 밝음 `#efe8d8`, 어두움 `#241f18` (테두리 없음)                                                   |
| 글자      | 잉크 `#14110d`, 어두움 `#f4eee0`                                                                           |
| 행동      | `--primary`는 잉크색(어두움에서는 반전), 주황 `--accent #ff6a2b`는 면에만 사용, 라임 `--highlight #d8ec6b` |
| 상태      | 옅은 면과 진한 글자 쌍 (성공·주의·위험), 진행 배지는 `--accent-subtle`                                     |
| 모서리    | 입력 16, 버튼 18, 카드 30~34, 칩·탭은 알약                                                                 |
| 깊이      | 그림자는 모달·팝오버·메뉴·툴팁에만, 지표 타일은 `tile-*` 클래스의 두께 테두리                              |

### 공통 컴포넌트 규칙

- 버튼: primary 잉크, secondary 모래, soft 라임. 화면 위쪽 행동 줄은 `pillIconButtonClass`(잉크 알약과 주황 아이콘 원)
- 입력: 모래 채움, 포커스는 잉크 테두리와 주황 링, 오류는 위험색 테두리와 옅은 면
- 탭·구간 선택: 트랙 안의 알약, 선택은 잉크 채움
- 지표 타일: 라임, 크림, 크림, 잉크(주황 숫자) 순서로 반복
- 제목 평면 안에서는 `--foreground`를 잉크로 고정해 다크 모드에서도 글자가 읽힘

## 확인 메모

- 스토리 접근성 검사(`pnpm test:stories`)에서 잉크 타일 위 상태색과 인력 배치 겹침 칸 글자색의 대비 부족이 나와 고쳤다
- Windows에서 `@swc/core` 캐시 권한 오류가 나면 `SWC_NATIVE_BINDING_CACHE`를 쓰기 가능한 폴더로 지정하고 실행한다
- Windows 예약 포트(5143~5242)와 겹치면 개발 서버가 `EACCES`로 뜨지 않으므로 4600번 같은 다른 포트를 쓴다
