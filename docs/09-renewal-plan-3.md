## 2. 공통 기준 (모든 화면에 먼저 적용)

### 2.1 화면 틀

- **본문 폭**: `max-w-6xl`(1152px) → **`max-w-[1600px]`**, 좌우 여백 `px-4 md:px-8 xl:px-10`. 1920px에서 본문 약 1600px. 읽는 글(설정 폼 등)은 구역 안에서 `max-w-2xl`로 따로 줄인다
- **왼쪽 메뉴**: 화면 높이 전체를 채우고(`sticky top-0 h-dvh`) 본문만 스크롤
- **프로젝트 서브 메뉴**: 가로 스크롤만(`overflow-x-auto overflow-y-hidden`), 스크롤바 숨김 + 넘칠 때 좌우 끝에 흐림 표시. 현재 탭이 보이도록 자동 스크롤. 넓은 화면은 한 줄에 다 들어감
- **프로젝트 머리**: 1줄 번호·이름·상태·남은 기간, 2줄 현장·고객·담당자·기간. 오른쪽 주 버튼 1개(진행 중이면 `오늘 기록`) + 더보기(⋯: 정보 수정·일보 출력·프로젝트 안에서 찾기)

### 2.2 버튼과 확인 창

- **버튼 기준**: 화면 주 동작은 구역 머리 오른쪽 `md` 버튼 1개. 폼 저장은 폼 끝 오른쪽 정렬 `md`. **전체 폭 파란 버튼은 모바일 시트·창 안에서만**. 표 행 동작은 아이콘 `icon-sm` 또는 더보기(⋯)
- **확인 창** `ConfirmDialog` + `useConfirm()` (Radix AlertDialog): 제목·무엇이 어떻게 되는지·되돌릴 수 있는지·확인 버튼(위험하면 빨강). 다음 동작은 모두 확인 창을 거친다 (구현 때 목록 전체를 스토리로 점검)

| 영역      | 동작                                                                                                |
| --------- | --------------------------------------------------------------------------------------------------- |
| 프로젝트  | 상태 변경(완료·중단·취소·종료·재오픈), 기간 단축                                                    |
| 하루 기록 | 기록 지우기(있다면), 다른 날짜에서 불러오기로 덮어쓰기                                              |
| 자재·지출 | 기록 지우기                                                                                         |
| 사진·문서 | 지우기, 문서 버전 지우기                                                                            |
| 추가 공사 | 철회, 증빙 연결 끊기·지우기                                                                         |
| 보증·보수 | 보증서 지우기, 보수 요청 상태 되돌리기                                                              |
| 직원·명부 | 퇴사 처리, 휴직 처리, 서류 지우기, 명부 지우기                                                      |
| 월 공수표 | 확정, 재오픈                                                                                        |
| 설정      | 원격 로그아웃, 다른 기기 모두 로그아웃, 소셜 연동 해제, 목록 항목 숨기기·지우기, **계정 해지 요청** |

### 2.3 사라지는 안내

- 입력 확인 안내(예: "기록할 자재를 한 줄 이상 적어 주세요")는 `FormNotice`로: **5초 뒤** 또는 본문 안 아무 곳이나 누르면 사라진다. 왼쪽 메뉴·서브 메뉴·뒤로 가기 같은 이동 영역을 누를 때는 사라지게 하지 않는다(이동하면 화면이 바뀌므로). 칸 옆 오류(빨간 테두리)는 고칠 때까지 남는다
- 서버 오류("저장하지 못했습니다")는 사라지지 않는 `Alert` 그대로 (놓치면 안 되는 정보)

### 2.4 선택 목록 높이

- 셀렉트·콤보박스·여러 개 고르기 목록은 **최대 약 8줄(320px)** 까지 보이고 그 뒤는 스크롤. 화면 아래가 좁으면 그만큼 줄인다 (`min(320px, 남은 높이)`). 지금 "전체 담당자" 목록과 같은 모양으로 통일

### 2.5 안내 문구 규칙

- 선택 입력은 **라벨 옆 "(선택)"**, 안내 줄은 **"예: …"** 만. "선택 (…)" 같은 섞인 형식은 쓰지 않는다
- 뻔한 안내는 지운다 (작업 구역의 "층·호실·동 (선택)")
- 날짜가 정해진 화면의 제목은 날짜를 넣는다: **"2026년 10월 14일 (수) 작업 내용"**, **"2026년 10월 14일 (수) 작업 사진"** (`formatLongDay`)

## 3. 프로젝트 화면

### 3.1 프로젝트 목록

- 표 열: 번호 · **프로젝트명** · **현장명** · 상태 · 고객 · 담당자 · 기간 · 공종 (현장명을 따로 열로)
- 맨 위 검색칸은 **프로젝트명·번호**만. 자세히 찾기에 **현장명** 칸을 따로 둔다 (고객·담당자·공종·기간과 함께)
- API: 목록 조회에 `site`(현장명 부분 일치) 추가, `q`에서 현장명 제외. shared 스키마·서버·목업·openapi 함께

### 3.2 하루 기록 (08 문서 §5.5 다듬기)

- 4단계 제목 "그날 작업" → **"2026년 10월 14일 (수) 작업 내용"**, 사진 구역 "이 날 사진" → **"2026년 10월 14일 (수) 작업 사진"**
- 작업 구역 안내 삭제, "날씨·특이사항" → **"특이사항"** (안내: "예: 비로 오후 작업 중단, 자재 입고 지연")
- 사진은 이 화면에서 바로 올린다 (사진 구역 머리 `사진 올리기`, 구분·구역 선택은 올린 뒤 사진마다). 사진 탭으로 보내지 않는다
- 메모도 이 화면에서 쓴다 (§3.5, 결정 필요 ②)

### 3.3 현황

- **진행 단계**: 예정 → 진행 → 완료 → 보증 → 종료를 잇는 가로 막대. 지나온 구간은 채운 색, 현재 단계 원은 진하게, 날짜(실제 시작일·완료일·보증 시작일)를 원 아래에
- 단계 아래 한 줄: `현재 상태 진행 · 실제 시작일 2026-07-15 · 실제 완료일 -` + **오른쪽 끝에 주 버튼(완료 처리)**. 중단·취소는 같은 줄의 더보기(⋯)로. 모두 확인 창
- 상태 변경 이력은 접힌 줄 그대로

### 3.4 인원: 일한 날 보여 주기

- "일한 기간" 열을 없애고 **"일한 날"** 을 `3일 · 최근 10월 10일`로 보인다
- 사람 이름(또는 `날짜 보기`)을 누르면 **창**: 그 사람이 이 프로젝트에서 일한 날을 **달력(월별, 일한 날에 시간 표시)** 과 **날짜 목록(날짜·시간·한 일)** 으로. 날짜를 누르면 그날 하루 기록으로 이동
- API: `GET /projects/:id/work-summary/employees/:employeeId` → `{ days: [{ workDate, minutes, categories }] }` (저장된 작업 내역만). 계산은 shared 순수 함수 `employeeProjectDays`

### 3.5 사진·메모: 모아 보는 곳

- **사진 탭**: 올리기 폼 제거. **작업 날짜별 묶음**(최근 날짜 먼저, 날짜 머리에 "2026년 10월 14일 (수) · 6장 · 작업 기록 보기"), 칩 필터(구분: 작업 전·중·후·하자…), 구역 찾기, 전후 비교 보기는 유지. 사진을 누르면 크게 보기(앞뒤 넘기기)·정보 고치기·지우기(확인 창). 작업 날짜가 없는 사진(예전 기록)은 "날짜 없음" 묶음
- **메모 탭**: 쓰기 폼 제거. 날짜별 목록 + 태그 칩 필터 + 할 일 체크(상태 바꾸기는 허용). 메모는 하루 기록의 "메모" 단계에서 쓴다 (결정 필요 ②)

### 3.6 문서

- 머리 설명: **"현장에서 보는 도면·작업지시서, 고객과 주고받은 계약서·공문, 안전·검사 서류를 판(버전)별로 보관합니다"**
- 분류를 **폴더 카드**로 (분류마다 무엇을 올리는지 예시 한 줄 + 문서 수): 도면·작업지시서 / 계약·공문 / 안전·검사 / 견적·정산 / 기타. 카드를 누르면 그 분류만
- 문서 목록은 표: 문서명 · 분류 · 최신 판(개정일) · 판 수 · 민감 표시 · 더보기(새 판 올리기·내려받기·지우기)
- `문서 올리기`는 머리 버튼 → 창: **끌어 놓기 영역**(PDF·이미지), 파일 이름으로 문서명 자동, 분류 카드 선택, 민감 자료 체크(설명: "열람·내려받기 기록이 남습니다"). 같은 이름 문서가 있으면 "새 판으로 올리기" 제안

### 3.7 추가 공사

- 목록을 표·카드 정리: 번호 · 내용 · 요청자 · 요청일 · 상태 · 증빙 수 · 쓴 공수. 새 기록은 머리 `추가 공사 기록` → 창
- 상세(창 또는 펼침)에 **증빙** 구역: `증빙 올리기`로 사진·공문(PDF·이미지)을 바로 올린다. 서버는 문서함에 "계약·공문" 분류 문서로 만들고 이 추가 공사에 연결 (기존 `ChangeWorkDocument` 연결 그대로, 새 테이블 없음). 문서함의 문서 연결도 유지
- 증빙은 썸네일 줄로 보이고 누르면 크게 보기

### 3.8 마감·보증 (신중히: 결정 필요 ③)

- **마감 요약 = 고객에게 내는 준공 보고서**로 정의하고 각 구역의 기준을 화면에 적는다
  - 사진: 지금은 "대표 사진 먼저 + 최근 찍은 순 상위 N장" → **"작업 후"·"전후 비교" 사진 중 관리자가 고른 것**(사진 탭에서 `요약에 넣기` 표시, 최대 12장). 고르지 않았으면 작업 후 사진 최근 8장을 기본으로
  - 문서: 지금은 "민감 자료가 아닌 모든 문서" → **"안전·검사"·"계약·공문" 분류 중 `요약에 넣기` 표시한 것**. 민감 자료는 표시해도 넣지 않는다
  - 자재 요약: 반입·반출·잔량 열 삭제 → **품명·규격·쓴 양** (08 문서 §6.3과 맞춤)
- **보증**: 완료 전에는 설정 폼을 숨기고 "프로젝트를 완료하면 보증을 설정할 수 있습니다" 한 줄 + 기본값(12개월, 실제 완료일부터)만 보인다
- **인쇄·PDF 저장**: 전체 폭 파란 버튼 → **하위 메뉴 줄 오른쪽 작은 보조 버튼(프린터 아이콘 + "인쇄·PDF")**. 일보 출력은 날짜 이동 옆에 같은 버튼, 엑셀 내보내기도 같은 줄의 보조 버튼

### 3.9 정보 수정

- 기본정보 폼은 넓은 화면 2열 유지, 저장 버튼은 폼 끝 오른쪽 `md`
- 아래를 **2열**: 왼쪽 `예정 기간 변경 이력`(표), 오른쪽 `필요 자격`(체크 칩 묶음, 바뀌었을 때만 `저장` sm 버튼이 나타남)

## 4. 인력 배치 개편 (레퍼런스: 자원 일정표)

레퍼런스: Float·Resource Guru·Teamdeck 같은 **사람 행 × 날짜 열 타임라인**. 사람을 행에, 시간을 열에 두면 여러 사람을 한 기간에서 비교하기 좋고(현장 인력 가용성 확인에 맞음), 연속된 날은 막대 하나로 이어 보여 줘야 칸을 하나하나 읽지 않아도 흐름이 보인다. 빽빽한 정보를 다 보이기보다 "누가 어디에 있고, 누가 비고, 어디가 겹치는지"를 바로 찾게 한다

- **위 요약 줄**: 이번 주 `투입 중 5명 · 비는 사람 2명 · 겹침 1건` (눌러서 해당 행으로 걸러 보기)
- **보기**: 1주 / 2주 / 월. 오늘 열 강조, 주말 흐리게
- **행**: 직원 (직종·상태). 묶음: 투입 중 / 비는 사람 / 휴직. 직종으로 거르기
- **막대**: 같은 프로젝트에 연속된 날은 **한 막대**로, 막대 안에 **프로젝트 이름**(번호 아님)과 프로젝트 색. 실제 일한 날은 진한 막대, 투입 기간만 있고 기록이 없는 날은 옅은 빗금 막대(계획)
- **겹침**: 같은 날 두 프로젝트면 칸을 위아래로 나눠 두 막대를 모두 보이고 빨간 테두리. 마우스를 올리거나 누르면 "최설치 · 10월 12일: A동 외장 판금 공사 8시간, B동 덕트 설치 투입" 설명
- **동작**: 막대를 누르면 그 프로젝트의 그날 하루 기록, 빈 칸을 누르면 그날 일한 사람으로 넣을 프로젝트를 고르는 창 (투입 계획 결정 ⑤에 따라)
- 모바일: 날짜를 가로로 넘기는 1주 보기, 행 머리(이름) 고정
- API: 기간의 투입·실제 기록을 사람별·날짜별로 주는 기존 인력 배치 조회에 `minutes`(실제)·`projectName` 추가

## 5. 회사 화면

### 5.1 월 공수표

- 머리 줄: 달 이동 · 확정 상태 배지 · 오른쪽에 `엑셀로 내보내기`(보조) · `공수 확정`(주, 확인 창)
- 수치 줄(StatGroup): 합계 MD · MM · 일한 사람 · 하루 기준시간 · 월 기준일수
- 본문 **2열**: 왼쪽 넓게 **직원 × 프로젝트 표**(행 직원, 열 프로젝트, 끝 열 합계 MD·MM, 아래 합계 행). `직원별 / 프로젝트별` 전환. 오른쪽 좁게 확정 안내·확정·재오픈 이력

### 5.2 설정

- **내 계정 (2열)**: 왼쪽 `계정`(회사·이름·이메일) + `보안`(비밀번호·이메일은 줄마다 `변경` 버튼 → 창) + `소셜 로그인`. 오른쪽 `로그인한 기기`
- **로그인한 기기**: 이 기기를 맨 위에. **유효한(만료되지 않고 로그아웃하지 않은) 로그인만** 보이고, 그중 이 기기가 아닌 것에만 `로그아웃`(확인 창). 30일 넘게 쓰지 않은 로그인은 "오래 쓰지 않음" 묶음으로 접고 `모두 로그아웃`. 줄마다 기기 이름 · **IP** · 마지막 사용
  - IP: 세션에 `ip_address`(로그인 때)·`last_ip`(마지막 사용) 추가. 개인정보 수집 항목이 늘어나므로 처리방침 수집 항목·보유 기간(로그인 유지 기간) 반영 (P5-5와 연결, 결정 필요 ⑥)
- **회사 관리**: 기준값 카드 2열(하루 기준시간 · 월 기준일수 · 공수 입력 방식). 월 기준일수 기본값 **20일** 로 바꾸고 근거를 안내에 링크 (결정 필요 ①)
  - 근거: 대법원 2024. 4. 25. 선고 2020다271650 판결이 도시 일용근로자의 월 가동일수를 22일에서 **20일**로 낮춤(대체공휴일 신설, 고용노동부 고용형태별 근로실태조사의 월평균 근로일수 변화 근거). 링크: 국가법령정보센터 판례 검색 `https://www.law.go.kr/precSc.do?query=2020다271650`
  - 참고(안내에만): 월급제 통상임금의 월 소정근로시간 209시간(주 40시간+주휴 8시간 기준)은 시간 환산 기준이라 MM 계산과 다르다
  - 이미 가입한 회사의 값은 바꾸지 않는다. `표준값(20일)으로` 버튼만 둔다
- **기록 조회 → 활동 기록**: 데이터를 **바꾼 일**을 남기고 보여 준다: 작업 내역 저장·수정·삭제, 자재·지출 기록 삭제, 사진·문서 삭제, 프로젝트 정보·상태 변경, 직원 정보·상태 변경, 단가 변경, 내보내기(엑셀·PDF), 월 공수 확정·재오픈. 종류 칩 필터(저장·수정·삭제·내보내기·확정) + 기간 + 프로젝트. 행을 누르면 바뀐 내용(전·후)
  - 인건비 조회·단가 조회는 화면에서 뺀다. 기록 자체는 민감 정보 열람 근거라 남겨 둘지 결정 (결정 필요 ④)
  - DB: `audit_action`에 변경 종류 추가(마이그레이션), 각 서비스에서 기록. 회사 범위·추가 전용 규칙 그대로
- **기타**: 계정 해지 요청은 비밀번호 확인 + 확인 창(되돌릴 수 있는 14일 유예 안내). 스토리로 확인 창이 뜨는지 시험

### 5.3 메모함 제거

- 왼쪽 메뉴·모바일 더보기·홈 카드·빠른 추가에서 메모함 제거. `/inbox`는 홈으로 이동. 프로젝트에 연결되지 않은 기존 메모는 데이터만 남긴다 (나중에 "전체 메모 모아 보기"를 만들 때 쓴다)

### 5.4 알림 (레퍼런스: 알림 센터 패턴)

레퍼런스 공통점: 알림은 **눌러서 해결할 곳으로 바로 가고**, **읽음·지우기(숨기기)** 가 있고, 같은 종류는 **묶어서** 보여 주며, 급하지 않은 알림이 늘 빨갛게 켜져 있으면 사람들이 보지 않게 된다

- 알림 한 줄 = 종류 아이콘 · **무엇이 어디서** · 언제 · `가 보기` · `숨기기`
  - 겹침 예: "최설치가 10월 12일~15일 **A동 외장 판금 공사**와 **B동 덕트 설치**에 함께 들어가 있습니다" → `인력 배치에서 보기`(그 주, 그 사람 행 강조)
  - 서류 만료 → 그 직원 카드 서류 탭, 미확정 월 → 그 달 월 공수표, 작업 기록 없음 → 그 프로젝트 그날 하루 기록
- 같은 종류가 3건 넘으면 묶음 ("서류 만료 임박 4건" 펼치기)
- `숨기기`는 그 알림을 조건이 바뀔 때까지 숨긴다 (예: 같은 겹침 구간이 그대로면 계속 숨김, 새 구간이 생기면 다시 보임). `모두 숨기기`
- 색: 오늘 처리해야 할 것만 빨강(만료됨, 오늘 기록 없음), 나머지는 기본색 + 점
- 왼쪽 메뉴 아래(모바일은 머리) **알림 버튼**과 숨기지 않은 개수(9+). 누르면 알림 목록 패널. 홈에는 상위 5개
- DB: `alert_dismissals`(회사·알림 종류·대상 키·숨긴 조건 값·숨긴 시각). 회사 범위 테이블 규칙(RLS·`PURGE_POLICY`·격리 시험)

### 5.5 홈 대시보드 개편

"오늘 무엇을 해야 하나"와 "현장들이 어떻게 돌아가나"를 한 화면에서 위계 있게:

1. **머리**: 인사 + 오늘 날짜, 오른쪽 `프로젝트 등록`
2. **수치 줄**: 진행 중 프로젝트 · 오늘 기록한 인원 / 투입 인원 · 이번 주 일한 시간 · 확인할 일
3. **2열**: 왼쪽(넓게) **진행 중 프로젝트 표**: 이름·현장 · 진행률 막대 · 남은 기간 · 오늘 기록 여부(있음/없음 + `기록하기`) · 이번 주 시간. 오른쪽(좁게) **확인할 일**(알림 상위 5개 + `모두 보기`)
4. **이번 주 인력**: 인력 배치의 1주 축소판 (사람 × 요일, 막대만)
5. 아래 작은 줄: 보증 종료 임박 · 서류 만료 임박 (있을 때만)

- 메모함·할 일 카드는 없앤다 (할 일은 확인할 일로 합침)

## 8. 결정 필요 (작업 전 확인)

1. **월 기준일수 표준값**: 20일(대법원 2024년 판결, 권장) / 22일(2003년 이후 쓰던 값) 중 무엇으로 할지
2. **메모 쓰는 곳**: 하루 기록 안 "메모" 단계(권장) / 현황 화면 / 둘 다
3. **마감 요약 사진·문서 고르는 방식**: 관리자가 `요약에 넣기`로 직접 고름 + 안 고르면 기본 규칙(권장, 컬럼 추가) / 분류·구분만으로 자동 (스키마 변경 없음)
4. **인건비·단가 조회 기록**: 화면에서만 빼고 기록은 남김(권장, 민감 정보 열람 근거) / 기록 자체를 멈춤
5. **투입 계획**: 인력 배치 빈 칸·작업 달력 앞날짜에서 미리 사람을 정해 두는 기능을 둘지 (08 문서 결정 2를 유지할지)
6. **로그인 IP 기록**: 개인정보 수집 항목이 늘어남 (처리방침 반영). 진행할지
